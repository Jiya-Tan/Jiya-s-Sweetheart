## How to add a product

1. Put the product image inside:
   `assets/products/`

2. Open `products.js`.

3. Find the relevant category.

4. Change a card from:

```js
{
  name:"Regency Gown",
  category:"THE DRESS",
  description:"Empire-waist satin gown for the full promenade silhouette.",
  image:"",
  url:"",
  price:"add price"
}
```

to:

```js
{
  name:"Regency Gown",
  category:"THE DRESS",
  description:"Your short product description.",
  image:"assets/products/regency-gown.jpg",
  url:"PASTE YOUR AMAZON ASSOCIATES AFFILIATE LINK HERE",
  price:"₹1,999"
}
```

The product automatically appears on the correct category page.

## Image naming

Keep filenames simple:

- `regency-gown.jpg`
- `pearl-necklace.jpg`
- `opera-gloves.jpg`

Avoid spaces and special characters.

## Amazon links

Use the affiliate links generated by your Amazon Associates account. Do not invent tracking parameters.

The site marks external product links with `rel="sponsored noopener noreferrer"`.

Keep the affiliate disclosure visible and follow Amazon's current Associates Operating Agreement and applicable Pinterest rules.

## Hosting for free

### GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Repository Settings → Pages.
4. Choose deployment from the `main` branch and root folder.
5. Save.
6. Use the resulting GitHub Pages URL as your Pinterest destination.

### Cloudflare Pages

Connect the GitHub repository to Cloudflare Pages and deploy as a static site. No build command is needed.

## Important for product photos

The starter leaves product images blank on purpose. Add images you have the right to use. For Amazon Associates content, follow Amazon's current rules regarding product images/content; don't simply scrape and host Amazon product images unless your current program terms permit it.

## Editing the homepage

The three images you uploaded are already used on the homepage:
- `home-angel-cross.png`
- `home-sweetheart.png`
- `home-gothic.png`

You can swap them by replacing those files or editing the `src` paths in `index.html`.

## Adding more categories

Copy one of the category HTML files, change `data-page`, and add a matching array to `STORE` in `products.js`.
